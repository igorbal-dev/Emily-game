# Игра для Эмили: главный документ проекта

Для Claude Code. Прочитать первым и сохранить в репозиторий как README или docs/project.md.

## Что это

Обучающая 2D-игра для Эмили (5 лет), дочери Игоря. Семья русскоязычная, живёт в Берлине. Эмили скоро идёт в немецкую школу. Играет на Android-телефоне и iPad.

## Цели

1. Немецкий для реальной жизни: здороваться, знакомиться, проситься в игру, покупать, просить помощи, день в садике.
2. Счёт: 1–10, прибавить/отнять один, больше/поровну, по одному каждому.
3. Общение: делиться, ждать очередь, мириться, принимать малыша в игру, безопасность на дороге.
4. Чтобы было весело и красиво: живые анимации в стиле простого мультика (уровень Peppa Pig или чуть лучше).

## Техника

- Веб-игра (HTML/JS), 2D. До сих пор жила как страницы-артефакты Claude: меню «Игра для Эмили (Spiel mit Emily!)» и по странице на уровень.
- Цель переноса: весь код в этом репозитории, публикация через GitHub Pages. На своём сайте должен заработать настоящий микрофон (в артефактах вместо него синяя кнопка «сказала»). Код микрофона уже есть.
- Управление: касание, перетаскивание, голос.

## Герои

- **Эмили**, 5 лет, главная героиня: золотисто-русые хвостики, розовая футболка. На улице: голубая куртка, жёлтый рюкзак, сиреневые кроссовки.
- **Марк**, младший брат \~1,5 года: рыжеватые кудряшки, синий комбинезон. Прячется, выглядывает, ходит неуверенно.
- **Тео**, собака мальтипу: абрикосовые кудри, синяя шлейка. За успехи получает косточки.
- Изабель, Пауль (друзья на площадке), Heike (воспитательница), пекарь, продавец мороженого.

## Картинки

- Эмили, Марк, Тео нарисованы в ChatGPT по фото, нарезаны на PNG с прозрачным фоном. Базовые 24 позы: https://claude.ai/artifact/4S9QqPLhejcH1cHSmYoBSF (пути sprites/<герой>\_<поза>.png). Позже добавлены: мимика Эмили, Эмили и Марк в уличной одежде, причёски-награды (лежат в коде страниц уровней).
- Изабель, Пауль, Heike, продавцы, фоны и предметы нарисованы кодом. В ChatGPT рисуем только реальных людей по фото.
- Новые листы из ChatGPT: сетка 4×2, белый фон, без теней и текста; фон убирает Claude. Промпт пишет Claude, Игорь генерирует и присылает.
- Бесплатные ассеты для окружения можно брать с Kenney, itch.io, OpenGameArt, только с свободной лицензией (лучше CC0) и в едином стиле. Перед выбором показать Игорю варианты. Ничего платного.

## Уровни (сделаны)

0. Hallo! — поздороваться с героями, счёт до 3.
1. Verstecken — прятки дома, счёт до 3/5/10, unter/hinter/in. ТЗ: https://claude.ai/artifact/HuwbdGpa4ChYkohnPWqQJ8
2. Spielplatz — знакомство с Изабель и Паулем, прятки на площадке.
3. Bäckerei — покупка выпечки, +1, монетки.
4. Geburtstag — день рождения Изабель, 6 свечей, делим торт.
5. Sandkasten — песочница, делиться, больше/поровну.
6. Kita-Morgen — утро в садике, мытьё рук, крючок по значку.
7. Eisdiele — мороженое, цвета и вкусы, очередь.
8. Kita-Weg — дорога в садик, светофор, счёт машин. 9–10. Уборка игрушек, рынок (точные названия см. в коде меню).
9. Ballspiel — мяч друзьям по имени, принять Марка.
10. Turnen — спортзал с Heike, команды, побыть ведущей.
13. Wer ist dran? — площадка: очередь на качелях, уступить горку, извиниться. ТЗ: docs/tz/level-13.md
14. Zu Besuch bei Paul — в гостях у Пауля и Frau Becker. ТЗ: docs/tz/level-14.md
15. Im Supermarkt — магазин с Марком, вопрос продавцу, оплата. ТЗ: docs/tz/level-15.md
16. Kita: Ich brauche Hilfe — просить помощи, пожалеть друга. ТЗ: docs/tz/level-16.md

Уровни 13–16 собираются из `lN.src.html` (`python3 tools/build_minigames.py`) и работают на общем движке разговорных уровней `js/talk.js`.

За каждые 5 косточек открывается новая причёска Эмили на главной.

## Общие правила игры

- Текста на экране нет, только картинки, значки и цифры.
- Всё сначала по-немецки, русская подсказка только после нескольких немецких.
- Эмили повторяет фразы вслух; громко сказала = засчитано.
- Ничего не нажато 5–8 секунд: нужное подсвечивается. Всё нажимаемое мягко пульсирует.
- Конфликты: выбор из двух картинок-сцен, неправильный выбор мягко объясняется.
- Без чужих брендов и персонажей.

## Как мы работаем

- Идеи Игорь обсуждает с Claude в чате, сюда приходят готовые инструкции.
- После каждой задачи коротко записывать в docs/progress.md: дата, что сделано, что проверить на iPad/телефоне.
