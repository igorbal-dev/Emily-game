# Промпт для новой сессии: заменить персонажей в игре на готовые куклы

Скопируй всё, что ниже линии, в новую сессию Claude Code (репозиторий igorbal-dev/Emily-game).

---

Репозиторий igorbal-dev/Emily-game. Задача: **заменить персонажей в игре на готовые куклы из Godot**.
Я (Игорь) не программист, пишу по-русски — отвечай просто и коротко.

## Две ветки
1. **Игра** — ветка `claude/emily-game-port` (HTML/JS, без сборщика). Работаем в ней. Сначала прочитай её `CLAUDE.md`
   (как устроены уровни, картинки, публикация `sh tools/publish.sh "…"`, правила игры). Сайт: https://igorbal-dev.github.io/Emily-game/
2. **Куклы** — ветка `claude/emily-godot-rig` (Godot 4.3). Здесь готовые персонажи. Её `CLAUDE.md` и `README.md` описывают устройство.
   Возьми её отдельной папкой, не переключая игру:
   `git fetch origin claude/emily-godot-rig && git worktree add ../rig origin/claude/emily-godot-rig`
   Godot и всё нужное ставит `sh tools/setup_godot.sh` (в папке `../rig`). Godot: `/opt/godot/Godot_v4.3-stable_linux.x86_64`.
   Посмотреть кукол вживую: https://igorbal-dev.github.io/Emily-game/puppets/ (кнопки персонажей, движений, одежды, лица).

## Где лежат готовые персонажи (в ветке `claude/emily-godot-rig`)
Все смотрят вправо (вид 3/4), `facing = -1` — влево. Начало координат — земля между ступнями. Рост: Эмили и Абиха ~520 единиц, Марк меньше (малыш ~1 год), Тео ~190 стоя.

| Персонаж | Сцена | Что внутри |
|---|---|---|
| Эмили | `emily/emily.tscn` (код `emily/emily.gd`) | векторное тело на скелете, голова из картинок `emily/head/` |
| Абиха | `abiha/abiha.tscn` (тот же код) | голова `abiha/head/`, одежда `abiha/outfits/` |
| Марк | `mark/mark.tscn` (тот же код) | голова `mark/head/`, одежда `mark/outfits/` |
| Тео (собака) | `theo/theo.tscn` (код `theo/theo.gd`) | покадровый, кадры `theo/frames/*.png` + `theo/frames.json` |

**Как управлять Эмили / Абихой / Марком** (`emily/emily.gd`):
- движения: `play("idle" | "walk" | "run" | "jump" | "spin" | "wave" | "talk" | "blink")`;
- глаза: `eyes = "open" | "half" | "closed" | "happy" | "surprised" | "sad"`;
- рот: `mouth = "smile" | "a" | "o" | "e" | "m" | "laugh"`; `talking = true` — рот двигается сам;
- причёска: `set_hair(...)` — Эмили: braids, bun, cap, flowers, headband, pigtails, ponytail, stars; Абиха: ponytail; Марк: curls, hat (шапка);
- одежда: `set_outfit({"top": "...", "bottom": "...", "socks": "...", "shoes": "...", "outer": "...", "dress": "..."})`, `null` — снять;
  список вещей = файлы `.tres` в `<персонаж>/outfits/`.
  Готовые комплекты Абихи — `abiha/outfits/sets.json` (дома: пижамы; улица; зима).
- `auto_blink = false` — чтобы на снимке не моргала.

**Тео** (`theo/theo.gd`): `play(...)` — idle, wag, happy, walk, trot, run, jump, shake, bark, sit, tilt, beg, sniff, dig, lie, sleep, hide, front, back, blink.

**Готовые инструменты для снимков** (смотреть как пример):
- `tools/shot_poses.gd` — персонажи в позах рядом (`xvfb-run -a godot --path . --rendering-driver opengl3 --script res://tools/shot_poses.gd -- out.png res://abiha/abiha.tscn outfit=top:jacket_pink,bottom:jeans_blue poses=idle:0,walk:0.2`);
- `tools/render_previews.gd` — кадры всех движений в `previews/`;
- рендер только так: `xvfb-run -a … --rendering-driver opengl3`.

## Как сейчас персонажи сделаны в игре
Это обычные картинки: ключи в `art/*.json` (например `art/race_img.json`, `art/talk_img.json`: ключ → `assets/img/<хэш>.webp`, ширина, высота),
спрайты `assets/sprites/*.png`, словари `IMG` внутри страниц уровней, Абиха — `tools/abiha_game.py` (ключи `abiha_<поза>` и `abiha_<поза>_out`).
Часть второстепенных героев нарисована кодом (`personSVG` в `js/scenes.js`) — их не трогаем, если я не скажу.

## Что сделать
1. **Найти все картинки Эмили, Марка, Абихи и Тео в игре** (ключи, где используются, какая поза/эмоция/одежда на каждой).
   Показать мне коротко: сколько их и какие группы (стоит, машет, бежит, едет на самокате…).
2. **Написать скрипт снимков в ветке кукол** (например `tools/render_for_game.gd`): для каждого ключа — кукла в нужной позе,
   с нужными глазами/ртом/одеждой, **прозрачный фон** (`get_viewport().transparent_bg = true`), обрезка по краям,
   один масштаб для всех кадров одного персонажа (чтобы рост не прыгал), сохранение в webp как в игре.
   Таблицу «ключ → персонаж, движение, момент, глаза, рот, одежда, причёска» держать в одном файле (JSON), чтобы легко правилась.
   Скрипт закоммитить в `claude/emily-godot-rig` (только новые файлы, кукол не менять).
3. **Сначала пробный уровень**: заменить картинки на одном уровне, опубликовать, дать мне ссылку — я посмотрю на телефоне.
   Только после «да» — все остальные уровни и мини-игры.
4. Позы, которых у кукол нет (например, едет на самокате, держит предмет, сидит), — **не выдумывать**:
   составь список и спроси меня, что с ними делать (оставить старую картинку / собрать позу из костей / пропустить).
5. Если для движения в игре нужна анимация (ходьба, бег), можно снять несколько кадров вместо одной картинки — сначала спроси.

## Правила
- Ключи картинок не менять — меняются только файлы, на которые они указывают. Старые картинки не удалять (есть прошлые версии сайта `vN/`).
- Размер сайта: `publish.sh` пишет его в конце; после ~800 МБ сказать мне.
- Кукол в ветке `claude/emily-godot-rig` не менять (одежду, головы, движения). Нужна правка куклы — сначала спросить.
- Игру коммитить в `claude/emily-game-port`, публиковать `sh tools/publish.sh "что нового"`. `main` не трогать.
- Перед публикацией одна короткая проверка (снимок страницы или картинок), долгие автопрогоны не гонять.
